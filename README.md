# 사유 · Thought Map

v0.4 기반 정적 PWA. Mac, Windows, iPad의 브라우저에서 사용하며 Docker나 운영 서버가 필요하지 않습니다.

## 저장과 이전

- 편집 내용은 기기 브라우저의 IndexedDB `sayu-local-v1`에 자동 저장됩니다. 기존 저장소와 JSON v1 형식을 유지합니다.
- Microsoft 등록 없이 사용: Mac·Windows의 Chrome/Edge에서 **저장소 · 설치 → 기기 폴더 선택 · 연결**로 OneDrive가 동기화하는 폴더를 선택합니다. iPad·Safari에서는 **파일로 저장 / 공유 → JSON 파일 열기**로 수동 전달할 수 있습니다.
- 가져오기 전 내용을 미리 확인합니다. 교체된 작업실은 기기의 복원 기록에 최대 20개 보관됩니다.
- 기존 사이트와 GitHub Pages는 주소가 달라 브라우저 저장소가 공유되지 않습니다. **기존 사이트에서 JSON을 내보낸 뒤 새 주소에서 가져오세요.** 기존 사이트 데이터나 OneDrive 파일을 삭제하지 않습니다.
- 브라우저 데이터 삭제나 앱 제거 전 JSON을 내보내세요. 개인정보와 백업 JSON은 GitHub에 올리지 마세요.

## 맵과 생각 정리

- 맵의 **(…) → 맵 삭제**에서 확인 후 삭제합니다. 안의 생각은 Inbox에 보관되고 연결은 해제됩니다. 실행 취소로 되돌리거나 **저장소 · 설치 → 복원 기록**에서 삭제 전 작업실을 복원할 수 있습니다.
- 맵을 폴더로 끌어 옮기면 대상 폴더가 강조됩니다. Inbox의 생각을 왼쪽 맵으로 끌어 옮기거나 행의 맵 선택 메뉴를 사용합니다.
- 상단 왼쪽 버튼으로 사이드바를 접고 펼칩니다. 안내 문구와 저장 요약을 줄여 MY MAPS 영역을 넓혔으며 저장·오프라인 상태는 **저장소 · 설치**에서 확인합니다.
- 생각 종류는 **메모 → 질문 → 주장 → 근거 → 개념 → 사례** 순서입니다. 노드 테두리 색으로 종류를, 연결의 색·선 모양·기호로 **관련·지지·반박·원인·구체화**를 구분합니다.
- 선택한 노드나 연결은 **Delete / Backspace**로 삭제하고 실행 취소할 수 있습니다. 제목·본문 등 입력 영역에서는 글자 편집 키로 동작합니다.
- 맵 도구의 **맵 중앙 맞추기**로 전체를 맞추고 **미니맵 보기/숨기기**로 표시를 전환합니다. 미니맵의 위치나 노드를 클릭하면 해당 지점으로 이동합니다.

## 배포

`npm ci`, `npm run typecheck`, `npm test`, `npm run build`.
GitHub 저장소 Settings → Pages → Source를 **GitHub Actions**로 지정합니다. main에 push하면 `.github/workflows/pages.yml`이 `portable-dist`를 배포합니다.
배포 주소: https://ds-edwin.github.io/sayu/

첫 방문은 온라인으로 진행하고 **저장소 · 설치**에서 ‘오프라인 자료 설치 완료’를 확인하세요. 업데이트는 열린 앱 탭을 모두 닫은 뒤 다시 열 때 적용됩니다. 캐시는 앱 경로별로 분리하며 다른 앱 캐시나 작업 데이터는 삭제하지 않습니다.

## Microsoft 앱 등록 없는 기기 폴더 연결

1. 각 Mac·Windows에서 OneDrive 앱에 같은 계정으로 로그인하고 동기화가 끝날 때까지 기다립니다.
2. OneDrive 안에 사유 전용 폴더(예: `OneDrive/사유`)를 만듭니다. 오프라인에서도 사용할 파일은 기기에 내려받아 유지하세요.
3. Chrome/Edge의 사유에서 **저장소 · 설치 → 기기 폴더 선택 · 연결**을 눌러 각 기기에 동기화된 같은 폴더를 선택합니다. 브라우저의 읽기·쓰기 접근 요청을 허용합니다.
4. 폴더 내용과 기기 내용이 다르면 사용할 버전을 선택합니다. 선택 전에는 기존 내용이 자동으로 교체되지 않습니다.
5. **앱을 열어 둔 동안 폴더 자동 저장·불러오기**를 켭니다. 저장 뒤 약 5초 및 1분마다 확인합니다. 재실행 후 권한이 필요하면 **폴더 접근 허용 · 동기화**를 누릅니다.

선택한 폴더 안의 `sayu-versions`에 새 버전 JSON을 추가하며 기존 파일이나 다른 문서는 수정·삭제하지 않습니다. 동시 수정은 충돌로 표시하고 원본을 보관합니다. 폴더 연결을 해제해도 기기 내용과 폴더 파일은 보존됩니다. 폴더에 저장했다는 앱 표시는 OneDrive의 서버 업로드 완료를 의미하지 않습니다. 다른 기기로 전환하기 전에 OneDrive 앱의 동기화 상태를 확인하세요.

이 기능은 데스크톱 Chrome/Edge의 File System Access API를 이용합니다. iPad·Safari에서는 폴더에 지속적으로 읽기·쓰기하는 API가 없어 JSON 파일 열기·저장으로 전달해야 합니다. `sayu-versions` 안의 버전 JSON도 사유에서 가져올 수 있습니다. 모든 기기의 자동 동기화가 필요하면 아래 온라인 연결을 사용합니다. 기기 폴더와 온라인 OneDrive는 별도 저장소이며 자동 동기화는 한 방식씩 켭니다.

## 선택 사항: 개인 OneDrive 온라인 자동 동기화

Microsoft Entra 앱 등록에서 개인 Microsoft 계정을 허용하고 SPA 리디렉션 URI를 정확히 `https://ds-edwin.github.io/sayu/`로 등록합니다. Microsoft Graph 위임 권한은 `Files.ReadWrite.AppFolder`입니다. Client Secret은 필요하지 않습니다. 앱의 저장소 설정에서 Client ID와 모든 기기에 동일한 작업실 이름을 입력합니다.

기존 스냅샷과 충돌 원본을 유지합니다. Microsoft 앱 등록과 실제 계정 로그인 전에는 실계정 동기화를 검증할 수 없습니다.

## 설치

iPad: Safari → 공유 → 홈 화면에 추가. Mac: Safari → 파일 → Dock에 추가. Windows: Edge/Chrome → 앱 설치. JSON 파일 전달은 각 기기의 OneDrive 앱 또는 파일 선택기를 이용합니다.
