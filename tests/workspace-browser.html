실제 useWorkspace 저장 회귀 검증

사용한 적 없는 전용 localhost 포트에서만 실행하세요. 예: 저장소 루트에서 아래 서버를 연 뒤 http://127.0.0.1:4189/tests/workspace-browser.html로 접속합니다.

node node_modules/vite/bin/vite.js . --config portable/vite.config.ts --host 127.0.0.1 --port 4189 --strictPort

시작 시 기존 IndexedDB 또는 서비스 워커가 있으면 중단합니다. 검증용 DB는 삭제하지 않으며 재검증에는 새로운 포트를 사용하세요. 실제 OneDrive 인증·업로드나 물리 iPad 검증은 포함하지 않습니다.
